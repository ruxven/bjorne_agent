34// Parses the whole command line: global flags, an optional subcommand, and the
35// positional arguments.
36//
37// The first positional argument is a subcommand when it exactly matches a
38// reserved verb. Otherwise the bare form runs `run`. A task that begins with a
39// reserved word is spelled `bjorne_agent run "init the project"`.
40//
41// Flags may appear before or after the subcommand. `--` ends flag parsing, so
42// a task that begins with a dash can still be passed.
43//
44// Returns false on an unknown option, too many arguments, or a missing config
45// file, with the reason in error.
46bool parse(const std::vector<std::string>& arguments, Invocation& out, std::string& error);
