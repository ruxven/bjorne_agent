10// The ACP transport: newline delimited JSON-RPC over standard input and
11// standard output. Standard error is left alone, so the log lines the agent
12// writes never reach the editor as protocol messages.
13//
14// The reader keeps whatever it has already read, because a message may arrive
15// in pieces. The write side is synchronous, so a message reaches the editor
16// before the call returns.
17//
18// The descriptors are injectable so a test can drive the transport over a
19// pipe. The default is standard input and standard output.
